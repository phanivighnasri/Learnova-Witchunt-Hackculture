# Learnova

AI-Powered Accessible Virtual Science Labs

Learnova transforms any phone into an interactive science laboratory using AI, motion sensors, and accessibility-first design.

Built for Witch Hunt Hackathon 2026.

---

## Features

- Interactive Chemistry, Physics, and Biology labs
- Tilt-to-pour and shake-based experiments
- AI-powered explanations using Groq API
- Accessibility-first design
- Blind mode with voice navigation
- Dyslexia-friendly learning mode
- Real-time experiment feedback
- Mobile-first responsive experience
- Offline-friendly support

---

## Tech Stack

Frontend:
- Next.js
- React
- Tailwind CSS

APIs & Features:
- Groq API
- DeviceOrientation API
- DeviceMotion API
- Web Speech API

Deployment:
